模型配置 任务配置 统计与记录权责
平台统一接入基座模型，智能体在创建时可从中选择。接入方式、调用限额与默认模型由平台管理员维护；默认模型为新建智能体的初始基座。
模型限速与熔断策略走企业网关统一治理
模型名称提供方接入方式默认场景调用限额状态操作
任务类型配置 业务对接配置
核心区别：任务是可执行实体（创建 → 分配 → 处理 → 结果回传 → 归档，Trace ID 全链路留存），任务类型是权限与流转载体——类型决定 谁能看、谁能处理、由哪些智能体订阅、创建时必须提交哪些参数。任务类型 = 一级类型 + 二级类型，由有「任务配置」权限的用户维护，保存即生效，不设审核环节，关键属性变更留痕。
业务系统对接需在平台完成配置。业务侧实现具体任务流程；平台提供三类能力：任务分类定义、主/关联任务创建、任务查询。业务系统仅可调用创建已获权的任务类型，未获权类型对来源系统不可见。

平台留存全执行记录

两组授权：功能权限决定用户能进哪些页面、能用页面内哪些敏感功能（如平台配置 → 任务配置）；数据管理权限决定用户能维护哪些对象（智能体 / 知识库 / 项目空间 / 技能库 / 任务类型）。保存即生效，无权限的入口前端不渲染，接口每次操作重新校验。
