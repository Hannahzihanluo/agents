任务类型配置 业务对接配置
核心区别：任务是可执行实体（创建 → 分配 → 处理 → 结果回传 → 归档，Trace ID 全链路留存），任务类型是流转载体——类型决定 创建时必须提交哪些参数（参数名称 + 参数描述，可配多项）；不配置处理主体、不配置订阅智能体，派单由业务系统定义，建任务时带上处理人。任务类型 = 一级类型 + 二级类型，由有「任务配置」权限的用户维护，保存即生效，不设审核环节，关键属性变更留痕。
业务系统对接需在平台完成配置。业务侧实现具体任务流程；平台提供三类能力：任务分类定义、主/关联任务创建、任务查询。业务系统仅可调用创建已获权的任务类型，未获权类型对来源系统不可见。
