## 一、概述

### 1.1 需求背景

AI 工作台顶部的「我的工作看板」此前是写死的一组销售指标：跟进中商机、业绩数据、目标完成率、待跟进客户。这套指标只对销售角色成立，客户成功、项目经理、交付等角色进来看到的是与自己无关的数字，看板反而成了干扰。

问题不在于"再加几个指标"，而在于**指标口径没有配置入口**：

- 指标的数据从哪张表来、按什么规则过滤，只存在于代码里，业务方看不到也改不了。
- 不同角色需要不同的看板，但没有地方声明"这个看板属于谁"，也没有地方控制"谁能看到它"——看板上是业绩、SLA、风险项目这类带口径的经营数据，不该所有人进工作台都能看全。
- 看板上的数字是死的，看到异常数字后无法继续追问，用户还得自己去找对应的智能体重新描述一遍问题。

本需求把看板变成**技能库里的一类可配置资产**：由业务负责人在智能体平台「技能库 · 看板」中配置看板归属角色、执行智能体、以及每个指标磁贴的数据源与查询规则；配置启用后即时出现在 AI 工作台的「我的工作看板」下拉中；用户点任一磁贴，即以配置好的「关联输入」向该看板的执行智能体发问，把静态数字变成可继续深挖的对话。

看板配置与「数据表」tab 是配套关系：数据表定义统一取数口径，看板指标的数据源从已接入的数据表中选择，避免各看板各自解释数据。

| 序号 | 需求项 | 优先级 | 说明 |
|------|--------|--------|------|

| 2 | 看板配置弹窗 | P0 | 配置看板名称、所属角色、执行智能体、启用状态 |

## 三、需求正文

### 1. 产品定义

**看板**是技能库中的一类配置资产，作用是把某个角色日常最需要盯的几个数字，以固定口径固定顺序呈现在 AI 工作台顶部，并作为向智能体发问的入口。

一个看板由三部分构成：

- **归属声明**：看板名称、所属角色、执行智能体 —— 说明这块看板是给谁看的、由哪个智能体负责回答看板上的追问。
- **指标磁贴**：一组有序的指标，每个磁贴声明自己的展示样式（图标 / 名称 / 单位）、取数口径（数据源 / 查询规则）、以及被点击时向智能体发出的提问（关联输入）。
- **启用开关**：控制该看板是否出现在 AI 工作台的看板下拉中。
- **可用范围**：控制该看板对谁可见——公开可用（全员）或授权可用（仅被分享的用户），以及每个被授权用户拿到的权限档位。

看板不自己算数、不自己存数。数据源指向「数据表」tab 已接入的数据表，查询规则是对该表的过滤与聚合口径说明。看板配置的产物是**口径声明**，取数由平台按声明执行。

### 2. 处理流程

**看板配置**

```
业务负责人进入 智能体平台 → 技能库 → 看板 tab
 → 看到全部看板卡片（含已停用），每张卡片可见所属角色、执行智能体、磁贴数、是否已在工作台展示
 → 新建看板 或 打开已有看板配置
     → 填写看板名称（必填）、所属角色、执行智能体
     → 配置指标磁贴：逐条填写图标、指标名称、单位、数据源、查询规则、关联输入
     → 调整磁贴顺序（上移 / 下移）、删除不需要的磁贴
     → 设置启用状态
 → 保存
     → 启用中：立即出现在 AI 工作台「我的工作看板」下拉中（受可用范围约束）
     → 已停用：保存但不在工作台展示
 → 列表页也可直接切换启停，无需进入配置弹窗
```

**看板分享（可见范围授权）**

```
业务负责人在 看板卡片 点「分享」
 → 选择可用范围
     → 公开可用：全员在工作台可见，无需逐个授权
     → 授权可用：仅授权名单内的用户可见
         → 搜索用户名，勾选待新增的用户（已授权的置灰、不可重复勾选）
         → 选择分配权限：可使用 / 可配置
 → 查看「已授权用户 N」，可展开名单核对，并移除不再需要的授权
 → 确定
     → 授权即时生效：被授权人下次进入工作台即可在看板下拉中看到该看板
     → 被移除授权的用户，该看板从其工作台下拉中消失
```

**看板消费**

```
用户进入 AI 工作台
 → 顶部「我的工作看板」按当前选中的看板渲染磁贴网格
     → 下拉可切换到其他已启用的看板
     → 悬浮任一磁贴，显示该指标的数据源与查询规则
 → 点击某个磁贴
     → 自动切换到该看板配置的执行智能体（未在工作台的先加入）
     → 以该磁贴配置的「关联输入」作为用户提问发出
     → 智能体返回数据卡片：明细列表 + 结论解读 + 后续动作按钮
     → 后续动作可继续在看板内跳转（看其他指标）或转为具体行动（派任务 / 起草 / 去经营看板）
```

**配置与消费的联动关系**

```
数据表 tab（统一取数口径）
   ↓ 作为磁贴「数据源」的可选项
看板 tab（口径声明：角色 / 智能体 / 磁贴）
   ↓ 启用即生效
看板 tab（口径声明：角色 / 智能体 / 磁贴）
   ↓ 启用即生效
看板分享（可用范围 + 授权名单）
   ↓ 按登录人过滤可见看板
AI 工作台 · 我的工作看板（渲染 + 悬浮看口径）
   ↓ 点击磁贴，带上「关联输入」
执行智能体会话（数据卡片 + 后续动作）
```

工作台可见看板的判定：`已启用 且（可用范围=公开可用 或 当前登录人在授权名单内）`。启用开关管"这个看板还用不用"，可用范围管"这个看板给谁看"，两者是与的关系。

### 4. 原型及需求说明

#### 4.1 技能库·看板 tab

**整体功能说明**

「看板」是技能库的第五个 tab，与 Skills、MCP、工具、数据表并列。tab 标题带「新」标记。

进入后展示全部看板的卡片列表（两列网格），**包含已停用的看板**——停用不等于删除，配置需要保留可见以便随时恢复。列表头部有一行说明：「按角色配置指标看板，启用后出现在 AI 工作台「我的工作看板」下拉中」。

底部操作条的按钮文案随 tab 切换，在看板 tab 下为「+ 新建看板」，点击直接打开空白的看板配置弹窗。

**逻辑处理说明**

| 处理项 | 逻辑 |
|--------|------|
| tab 切换 | 五个 tab 互斥切换；切到看板 tab 时隐藏上方的技能筛选区（授权状态、名称搜索、智能体筛选对看板不适用），也隐藏「自动创建 Skill」入口 |
| 卡片启停 | 卡片上的启用开关可直接切换，无需进入配置弹窗；切换后即时同步 AI 工作台的看板下拉，并提示「已启用，工作台下拉中可选」/「已停用，工作台不再展示」 |
| 配置 | 打开看板配置弹窗，加载该看板的现有配置 |
| 分享 | 打开看板分享弹窗，设置可用范围与授权用户，详见 4.4 |
| 复制 | 以当前看板为模板创建副本，用于同类角色快速派生看板 |
| 删除 | 删除该看板配置；若该看板正在工作台展示，删除后工作台下拉同步移除，当前选中态回落到第一个可用看板 |
| 磁贴预览 | 卡片内以缩略网格展示该看板的磁贴，悬浮可看到数据源、查询规则、关联输入，不进入弹窗也能核对口径 |

**字段说明**

| 字段 | 说明 |
|------|------|
| 看板名称 | 卡片主标题，如「销售看板」「客户成功看板」「项目经理看板」 |
| 所属角色 | 该看板服务的角色，如 销售 / 客户成功 / 项目经理；用于说明看板的目标用户 |
| 执行智能体 | 负责回答该看板追问的智能体，如 路书（销售AI）/ 客成助手 / KA 主理智能体 |
| 磁贴数量 | 该看板配置的指标个数 |
| 启用状态 | 启用 / 停用；启用后出现在 AI 工作台看板下拉中（仍受可用范围约束） |
| 工作台展示状态 | 由启用状态派生的文案：工作台已展示 / 已停用 |
| 可用范围 | 公开可用 / 授权可用，以标签形式展示在角色标签之后；两者视觉上区分（公开可用为蓝色系，授权可用为绿色系），便于列表中快速识别哪些看板是全员可见的 |
| 已授权人数 | 授权可用时显示「已授权 N 人」，公开可用时显示「全员可见」；用于不打开分享弹窗也能判断授权面 |

#### 4.2 看板配置弹窗·基本信息

**整体功能说明**

弹窗顶部一行说明配置的生效方式：「看板配置即生效：启用后出现在 AI 工作台「我的工作看板」下拉中，磁贴按此顺序展示，点磁贴以「关联输入」向执行智能体发问」。

基本信息为四列并排：看板名称、所属角色、执行智能体、启用开关。

**逻辑处理说明**

| 处理项 | 逻辑 |
|--------|------|
| 新建 | 名称默认「新建看板」，执行智能体默认取智能体列表第一个，启用默认开，磁贴为空 |
| 编辑 | 打开时加载该看板配置的副本，取消不影响原配置，仅保存时写回 |
| 执行智能体候选 | 下拉候选为平台已有智能体的并集，来源包括 MCP、数据表、工具、功能型技能、流程型技能所关联的智能体，以及已有看板已选的智能体 |
| 保存校验 | 看板名称必填，为空时提示「请填写看板名称」并阻断保存 |
| 保存后 | 关闭弹窗，刷新配置列表与 AI 工作台看板；启用中提示「看板「X」已保存，工作台已同步生效」，停用中提示「已保存，当前为停用状态」 |

**字段说明**

| 字段 | 必填 | 说明 |
|------|------|------|
| 看板名称 | 是 | 展示在配置列表卡片与工作台看板下拉中 |
| 所属角色 | 是 | 该看板服务的角色。未填写时按「未分配」处理，不阻断保存，但配置列表会以「未分配」显示，提示配置未完整 |
| 执行智能体 | 是 | 该看板磁贴被点击时接手提问的智能体。选择后，用户点磁贴会自动切到该智能体的会话 |
| 启用 | 否 | 默认开启。停用后工作台不再展示，但配置保留 |

#### 4.3 看板配置弹窗·指标磁贴

**整体功能说明**

磁贴区是一张可编辑表格，每行一个指标，列结构为：序号、图标、指标名称、单位、数据源、查询规则、关联输入、操作。表头上方有说明：「数据源取自「数据表」tab · 查询规则与关联输入决定磁贴口径与提问」，右侧为「+ 添加磁贴」。

磁贴为空时显示空态：「暂无磁贴，点右上「+ 添加磁贴」」。

**逻辑处理说明**

| 处理项 | 逻辑 |
|--------|------|
| 添加磁贴 | 在列表末尾追加一行，带一组占位默认值（图标 📌、名称「新指标」、单位「项」、数据源取数据表第一项、查询规则与关联输入为示例文案），用户在行内直接改 |
| 数据源选择 | 下拉候选为「数据表」tab 中已接入的数据表名称，不允许手填。目的是保证看板取数只走统一口径的数据表 |
| 排序 | 上移 / 下移调整磁贴顺序；该顺序即工作台上磁贴的展示顺序，首位为该角色最需要优先看的指标 |
| 删除 | 删除该行磁贴，其余磁贴序号自动重排 |
| 编辑生效范围 | 弹窗内的增删改排序都是对副本操作，保存后才写回看板配置并同步工作台 |

**字段说明**

| 字段 | 说明 |
|------|------|
| 序号 | 磁贴顺序，与工作台展示顺序一致，由排序操作决定，不可直接编辑 |
| 图标 | 一个 emoji，用于工作台磁贴的视觉区分 |
| 指标名称 | 磁贴主标题，如「跟进中商机」「目标完成率」「SLA 达成率」 |
| 单位 | 指标值的单位，如 个 / 万 / % / 项 / 单；随数值一并展示 |
| 数据源 | 该指标取数的数据表，选自「数据表」tab；工作台磁贴悬浮时展示 |
| 查询规则 | 该指标的过滤与聚合口径，如「负责人=我 且 阶段∈CR2–CR4 且 未签约」「归属销售=我 且 归属月份=本月 · SUM(签约金额)」「本月签约额 ÷ 月目标 500 万」。工作台磁贴悬浮时展示，让用户知道这个数字是怎么来的 |
| 关联输入 | 磁贴被点击时，以用户身份向执行智能体发出的提问，如「我现在跟进中的商机有哪些？各自阶段和金额」。这是把静态指标转成对话的关键字段 |

**配置示例（原型内置三套看板）**

| 看板 | 所属角色 | 执行智能体 | 磁贴 |
|------|----------|------------|------|
| 销售看板 | 销售 | 路书（销售AI） | 跟进中商机（个）· 业绩数据（万）· 目标完成率（%）· 待跟进客户（项） |
| 客户成功看板 | 客户成功 | 客成助手 | 在服客户 · 待处理 case · SLA 达成率 · 智能体承接率 |
| 项目经理看板 | 项目经理 | KA 主理智能体 | 在管项目 · 逾期任务 · 高风险项 · 本周完成 |

#### 4.4 看板分享与可见范围

**整体功能说明**

看板配好之后还要解决"给谁看"。看板上是业绩、SLA 达成率、高风险项目这类带口径的经营数据，全员可见并不合适；反过来，逐个用户去配一遍权限也太重。所以按**看板维度**做分享：一个看板要么公开可用（全员），要么授权可用（只给分享到的人），入口就是看板卡片上的「分享」。

分享弹窗与平台内 Skill、MCP、工具的分享保持同一套结构与文案，用户在技能库里的授权心智是一致的：可用范围 → 新增用户 → 分配权限 → 已授权用户。

弹窗自上而下：

- **可用范围**：授权可用 / 公开可用，单选。
- **新增用户**（必填）：上方为用户名搜索框（占位文案「请输入用户名搜索」），下方为可滚动的候选用户多选列表，展示用户名与账号名。
- **分配权限**：下拉，可使用 / 可配置，作用于本次勾选新增的用户。
- **已授权用户 N**：数量以链接样式展示，点击展开已授权名单，逐条显示用户名与权限档位，可单条移除。
- **底部**：关闭 / 确定。

**逻辑处理说明**

| 处理项 | 逻辑 |
|--------|------|
| 可用范围切换 | 选「公开可用」时，新增用户与分配权限区整体置灰不可操作（授权名单对公开看板无意义），已授权用户显示为「全员」；切回「授权可用」时恢复可操作，并回显原授权名单 |
| 用户搜索 | 按用户名或账号名模糊匹配，实时过滤候选列表；无匹配时列表区提示「没有匹配的用户」 |
| 已授权用户在候选中的表现 | 已在授权名单内的用户在候选列表中置灰、勾选框禁用，右侧标注「已授权」，避免重复授权与权限档位被静默覆盖 |
| 分配权限的作用范围 | 只作用于本次新增的用户；已授权用户的权限档位调整走"先移除再重新分享"，不在本弹窗内直接改档，保证一次操作只有一种语义 |
| 保存校验 | 可用范围=授权可用 且 授权名单为空 且 本次未勾选任何用户时，提示「请至少选择一个授权用户」并阻断保存。避免出现"授权可用但谁都看不到"的空授权看板 |
| 保存生效 | 确定后即时写回该看板的可用范围与授权名单，刷新配置列表与 AI 工作台看板下拉；公开可用提示「已设为公开可用，全员可在工作台看到」，授权可用提示「已授权 N 人（新增 M 人 · 权限档位）」 |
| 移除授权 | 在已授权名单中移除某用户后，该看板即时从该用户的工作台看板下拉中消失；若其当前正选中该看板，回落到其第一个可用看板 |
| 取消 | 「关闭」不写回任何改动，弹窗内的勾选与移除均为副本操作 |
| 新建看板的默认范围 | 新建看板默认可用范围=授权可用，并默认把创建人加入授权名单（权限档位 可配置），保证创建人自己能在工作台看到刚配的看板 |

**字段说明**

| 字段 | 必填 | 说明 |
|------|------|------|
| 可用范围 | 是 | 授权可用：仅授权名单内用户可在工作台看到该看板。公开可用：全员可见，不维护名单。默认授权可用 |
| 新增用户 | 是（授权可用时） | 本次要新增授权的用户，多选。候选来源为平台用户列表，与用户管理中的用户同一份数据 |
| 分配权限 | 是 | 可使用：仅能在工作台查看该看板、点磁贴发起查询。可配置：在"可使用"之上，可修改该看板的配置与分享范围 |
| 已授权用户 | — | 当前授权名单的人数与明细（用户名 + 权限档位），派生展示，不直接编辑 |

**权限档位与技能库功能权限的关系**

看板的「可使用 / 可配置」是**单个看板的对象级权限**，与用户管理里的「技能库」功能权限是两层，需同时满足：

- 只有具备「技能库 → 看板配置」功能权限的用户，才能进入看板 tab 看到配置列表与分享入口。
- 在此之上，才由看板自身的可用范围与权限档位决定他能操作哪些看板：拿到「可配置」的看板可改配置与再分享，只拿到「可使用」的看板在平台侧只读。
- 没有技能库功能权限的普通用户，完全不接触配置侧，但只要被分享到看板（或看板是公开可用），就能在 AI 工作台正常消费——**消费不依赖平台侧的功能权限**。

功能权限模型见《智能体平台 - 任务执行与任务配置》4.5。

#### 4.5 AI 工作台·我的工作看板

**整体功能说明**

AI 工作台顶部的「我的工作看板」是看板配置的唯一消费端。区域由三部分组成：看板选择下拉、磁贴网格、底部口径说明。

底部说明固定提示三件事：「看板与指标口径在「技能库 · 看板」配置 · 悬浮看数据源与查询规则 · 点任一指标即可让「X」在会话中展开查询」，其中 X 为当前看板的执行智能体。

**逻辑处理说明**

| 处理项 | 逻辑 |
|--------|------|
| 看板范围 | 下拉只列**已启用 且 当前登录人有权限**的看板：可用范围=公开可用，或登录人在该看板的授权名单内。停用的、以及未授权给本人的看板都不出现在工作台，且不做任何"存在但不可点"的提示——用户不需要知道有哪些看板与自己无关 |
| 默认看板 | 默认选中上次选择的看板；若该看板已被停用、删除或本人授权被移除，回落到第一个可用看板 |
| 切换看板 | 切换后重新渲染磁贴，并提示「已切换到「X」，对口智能体 Y」 |
| 网格列数 | 列数按磁贴数量自适应，最多 4 列，磁贴多于 4 个时换行 |
| 悬浮提示 | 悬浮单个磁贴展示三行：数据源、查询规则、「点击让「X」查数据」 |
| 指标取值 | 按磁贴配置的数据源与查询规则取数，返回指标值、辅助说明、以及数值的告警色（如目标完成率未达标显示为警示色） |
| 口径未接入 | 若某磁贴的取数口径尚未接入，指标值显示「—」，辅助说明显示「取数口径待接入」，磁贴仍可点击唤起智能体查询。目的是让新配的磁贴先可见，不因取数未就绪而挡住配置流程 |
| 空态 | 没有任何可用看板时（都未启用，或都未授权给本人），展示「暂无可用看板：需在 技能库-看板 里启用，且该看板为公开可用或已分享授权给你」，同时说明两个前提，避免用户只以为是没配置 |

**字段说明**

| 字段 | 说明 |
|------|------|
| 看板下拉 | 当前可选的启用看板列表 |
| 指标名称 | 图标 + 指标名称，过长截断 |
| 指标值 | 按查询规则算出的数值，未接入时为「—」 |
| 单位 | 紧随指标值展示 |
| 辅助说明 | 指标的补充信息，如同比、缺口、构成说明；口径未接入时为「取数口径待接入」 |

#### 4.6 磁贴点击唤起智能体查询

**整体功能说明**

看板的价值不止于展示数字，而在于**从数字直接进入追问**。点击磁贴后，平台代替用户完成"找到对口智能体、把问题描述清楚"这两步，用户看到的是一次正常的会话往来。

**逻辑处理说明**

| 处理项 | 逻辑 |
|--------|------|
| 智能体准备 | 若该看板的执行智能体尚未加入用户的工作台，先自动加入；若当前会话不是该智能体，自动切换 |
| 提问发出 | 以该磁贴配置的「关联输入」作为用户消息发出，消息下方标注来源「来自我的工作看板 · 指标名称」，让会话记录能追溯到入口 |
| 查询过程 | 智能体侧先显示查询中状态，文案带上看板名与数据源，如「正在查询销售看板 · CRM 商机表 口径数据…」 |
| 结果返回 | 返回结构化数据卡片，含三部分：明细列表（按该指标的口径列出条目）、结论解读（智能体对数据的判断与建议）、后续动作按钮 |
| 后续动作 | 动作按钮分两类：一是在看板内继续下钻（跳到相关指标的查询，如从业绩数据跳到漏斗转化）；二是转为具体行动（派跟进任务、起草内容、去经营看板、去任务中心） |

**字段说明**

| 字段 | 说明 |
|------|------|
| 数据卡片标题 | 该指标的汇总口径，如「跟进中商机 3 个 · 预计 670 万」 |
| 明细列表 | 三列结构：主体名称、关键数值、状态或阶段 |
| 结论解读 | 智能体基于明细给出的判断与下一步建议，不只是复述数字 |
| 后续动作按钮 | 1–2 个，指向下钻查询或具体行动 |

#### 4.7 与原型的差异说明

原型用于表达配置结构与联动关系，以下几处以本需求为准：

| 项 | 原型表现 | 本需求要求 |
|----|----------|------------|
| 配置持久化 | 配置仅存在于页面内存，刷新后回到初始的三套看板 | 看板配置需落库持久化，按配置人与角色留存 |
| 复制看板 | 仅弹出提示，未真正生成副本 | 需真实生成副本，名称默认加「副本」后缀，副本默认停用，避免误配置直接生效 |
| 所属角色 | 自由文本输入 | 需改为从平台角色数据中选择，保证与权限体系中的角色一致；同一角色可有多个看板 |
| 配置权限 | 任何进入技能库的用户都可配置与删除，未按看板权限档位区分可配置 / 可使用 | 按用户权限控制，不设审核流程：需有「技能库 → 看板配置」功能权限才可见看板 tab；在此之上，只有对该看板拿到「可配置」的用户才能改配置与再分享，拿到「可使用」的在平台侧只读。权限模型见《智能体平台 - 任务执行与任务配置》4.5 |
| 看板与用户的匹配 | 已实现按可用范围与授权名单过滤（公开可用 / 授权可用），登录人固定为当前 mock 用户 | 保持该判定逻辑，并补充按角色的默认授权：新建看板时可按「所属角色」批量授权该角色下的用户，避免逐个勾选；角色成员变动时授权名单自动跟随 |
| 授权名单的落地校验 | 仅前端过滤看板下拉 | 需前端渲染 + 服务端接口双层校验：查询某看板指标数据的接口需校验调用人对该看板的可见权限，防止绕过前端直接取数 |
| 权限档位调整 | 已授权用户改档位需先移除再重新分享 | 可在已授权名单中直接切换档位，减少两步操作；切换需留痕（操作人、时间、变更前后档位） |
| 分享操作留痕 | 未记录 | 分享、移除授权、可用范围变更均需记录操作日志，用于事后追溯"这个人当时为什么能看到这块看板" |
| 取数执行 | 磁贴取值由页面内的模拟数据算出，查询规则是展示文案而非执行逻辑 | 查询规则需成为可执行的取数配置，由平台按规则从数据表取数；规则不合法或数据表未同步时，磁贴按「取数口径待接入」降级展示，并在配置侧提示异常 |
| 磁贴数量 | 未限制 | 建议限制单看板磁贴数上限（如 8 个），超出后工作台展示效率下降；超限时保存给出提示 |
| 关联输入 | 纯文本，发出的提问固定 | 关联输入应支持变量占位（如当前用户、当前月份），避免为不同人不同周期配置多套提问 |

## 四、关联系统处理

### 4.1 与「数据表」的关系

看板的数据源必须来自「技能库 · 数据表」中已接入的数据表，不允许在看板侧另起口径。

- 新增看板指标时，若所需数据表尚未接入，需先在数据表 tab 添加并完成同步，才能在磁贴中选到。
- 数据表被删除或停止同步时，引用它的磁贴需标记异常，工作台侧按「取数口径待接入」降级展示，不静默显示错误数字。
- 与任务相关的看板指标（如待跟进客户、逾期任务、智能体承接率）统一取自「平台任务表」，与任务中心、跟进引擎共用同一份任务数据，保证看板上的待办数量与任务中心一致。

### 4.2 与智能体的关系

看板的「执行智能体」是看板与智能体能力的绑定点。

- 执行智能体需具备该看板数据源的访问授权，否则点磁贴后无法查数。配置保存时应校验该智能体是否已授权对应数据表，未授权时提示但不阻断（授权可后补）。
- 磁贴点击唤起的会话计入该智能体的正常会话记录，可在会话历史中回溯，来源标记为「我的工作看板」。
- 智能体被删除或停用时，引用它的看板需在配置列表标记异常，并提示重新指定执行智能体。

### 4.3 与 AI 工作台的关系

看板配置在智能体平台侧，消费在 AI 工作台侧，两端通过启用状态与可用范围联动：

- 配置侧的启用 / 停用 / 删除 / 磁贴顺序调整 / 可用范围与授权名单变更，均即时反映到工作台的看板下拉与磁贴网格，不需要用户手动刷新。
- 工作台的看板下拉是**按登录人过滤后**的结果，同一个看板对不同用户的可见性可能不同；工作台不展示"存在但无权限"的看板，也不提示申请入口（本期不做看板申请流程）。
- 工作台不提供任何看板编辑能力，只提供切换、悬浮看口径、点击查询。所有口径变更都回到技能库配置，保证口径只有一处定义。
- 看板底部固定标注配置位置，让用户看到不对的数字时知道去哪里改。

### 4.4 与「用户管理」的关系

看板分享的授权对象来自用户管理，两者是引用关系而非各自维护一份名单：

- 分享弹窗的候选用户列表取自平台用户列表，展示用户名与账号名，与用户管理中同一份数据。
- 用户被停用或删除时，其在各看板授权名单中的记录需同步失效，配置侧的「已授权 N 人」按有效用户重新计数。
- 「技能库 → 看板配置」功能权限决定用户能否进入配置侧；看板的可用范围与权限档位决定他在配置侧能操作哪些看板、在工作台能看到哪些看板。前者是页面级，后者是对象级，判定时两层同时生效。
