跨CR主线（调研最高频痛点）
主线一
线索质量守护线
电销SPIN收集不完整 → 销售重复问客户 → 客户反感 → 商机浪费。商机真实性/准确性是最高频痛点。
贯穿：CR1 → CR2
主线二
信息孤岛穿越线
销售↔客成↔Poe三方信息割裂 → 客户问进度 → 踢皮球 → 客户觉得销售不专业。
贯穿：CR4（交付部分） → CR5
主线三
区域 vs KA打法并行线
区域：当天成交不POC；KA：招投标+POC+多轮方案+底价审批。两条路径AI需求差异大。
贯穿：CR3 → CR4 → CR6
CR阶段定义
CR1
用户名单 → 市场线索
电销通过陌CALL/展会/官网等方式获取潜在客户名单，录入CRM
CR2
市场线索 → 准商机
对线索进行筛选验证，判断意向度和紧迫性，形成可跟进商机
CR3
准商机 → 行业方案介绍
方案团队输出行业方案，销售向客户介绍行业通用方案PPT
CR4
行业方案 → 客户方案 → POC → 商务谈判
KA专属链路：为客户定制方案 → POC测试 → 招投标 → 底价谈判
CR5
商务谈判后 → 全面实施交付
合同签署后，设备安装、软件部署、上线验收全过程
CR6
持续价值交付
设备运维、数据运营、季度汇报，让客户持续感知产品价值
CR7
交叉销售
老客户增购（新车/新仓库/新品类）、介绍新客户、转介绍
